# Zaihyo Parser

## 概要

Zaihyo Parser は、
財務諫表論教材を解析するためのParserです。

目的はPDFをCSVへ変換することではありません。

教材が持つ構造を解析し、
将来様々な学習形式へ変換できる中間データを構築することを目的としています。
